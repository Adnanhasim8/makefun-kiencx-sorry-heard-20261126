# Sorry, I Heard That Wrong

Entry for the make.fun competition `u-kiencx-sorry-i-heard-that-wrong-1858c729`: the funniest one-line apology a smart speaker gives after mishearing its owner. Ours misheard "buy milk" as "buy a cow" — and the cow is already in the driveway.

## How to run

```sh
python3 main.py
```

This writes the single entry line to `/output/entry.txt` (or to the directory given by `--out` / `MAKEFUN_OUTPUT_DIR`). Python 3.13 standard library only, no network at run time. The program asserts the output is exactly one line of 1–140 characters before finishing.
